## ٢) ألعاب الاشتراك (٣)

الاشتراك يفتح **Tower Guard** و **Dungeon Depths** و **Card Blitz** — وبما أن
**Reversi Duel** كان مدفوعًا من قبل، فالمدفوع في المكتبة الآن ٤ ألعاب. لتحويل Reversi إلى مجاني:
لوحة الإدارة ← الألعاب ← تعديل السعر.

الحماية مطبّقة على مستوى المسار: `/play/<slug>` لأي لعبة بريميوم يحوّل الزائر غير المشترك إلى
`/premium`، وصفحة اللعبة تعرض «Premium members only» بدلاً من الـ iframe.

### خطط الأسعار (نجوم Telegram — XTR)

| الخطة | السعر | المدة | الميزة |
|-------|-------|-------|--------|
| بريميوم · شهر | ٢٥٠ ⭐ | ٣٠ يومًا | كل الألعاب المميزة + بلا إعلانات |
| بريميوم · ٣ أشهر | ٦٥٠ ⭐ | ٩٠ يومًا | نفس ما سبق + وصول مبكر (خصم ١٣٪) |
| بريميوم · سنة | ٢٠٠٠ ⭐ | ٣٦٥ يومًا | نفس ما سبق (الأفضل قيمة) |

## ٣) البوت: تحويله إلى قمع اشتراكات

- `/start` يرسل **صورة ترحيب** (`public/brand/welcome.jpg`) مع نص مرحّب وثلاثة أزرار:
  «العب الآن» (فتح التطبيق)، «⭐ اشترك في بريميوم»، «👑 الألعاب المميزة».
- `/subscribe` أو زر الاشتراك ← قائمة الخطط الثلاث بأزرار.
- اختيار خطة ← إنشاء فاتورة **Stars** داخل المحادثة وزر دفع مباشر، بلا حاجة لفتح التطبيق.
- بعد الدفع يستقبل البوت `successful_payment` فيفعّل الاشتراك ويرسل تأكيدًا بتاريخ الانتهاء.
- قائمة أوامر البوت تُنشر تلقائيًا (`setMyCommands`) مع كل عملية بناء.
- إن فشل إرسال الصورة لأي سبب، يسقط البوت إلى رسالة نصية بدلًا من الصمت.

## ٤) الاختبار

```bash
npm run games:check      # يفتح الـ16 لعبة في jsdom، يشغّلها، يضغط الأزرار والأسهم، ويفشل عند أي استثناء
npm run bot:check        # يحاكي /start وزر الاشتراك وشراء خطة عبر اعتراض fetch (بلا شبكة)
npm run typecheck        # TypeScript
npm run smoke            # 38 فحصًا على قاعدة البيانات وHTTP
```

## ٥) إعادة توليد الأصول

```bash
npm run covers           # أغلفة الألعاب العشر (public/covers/*.jpg)
npm run welcome          # صورة ترحيب البوت (public/brand/welcome.jpg)
```

كل الصور متجهات (SVG) تُرسم بـ sharp — لا صور مقتبسة من الإنترنت، ولا حقوق طرف ثالث.
